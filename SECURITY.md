# Security policy

Earthquake Lab is a local educational application. It has no account system or project backend. Imported URLs and bundled observations still cross validation boundaries, and numerical work runs in a browser Worker. The Worker is not a hostile-code sandbox.

## Report a vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/steph4n-gh/earthquake-lab-publication/security/advisories/new). Private vulnerability reporting is enabled for this repository. Do not include exploit details, credentials, or private experiments in public issues.

Include the source revision, affected browser or native command, reproduction steps, and expected impact in the private report. The maintainer does not promise a response deadline.

## Supported code

Security fixes target the current `main` branch. The 0.1.0 preview has no long-term support guarantee. Do not use this educational model for emergency response, public warning, or operational earthquake location.
